# MyAI Health — Copy Glossary

Canonical terms for all user-facing copy in the portal and email templates.

| Use this | Not this |
|---|---|
| **sign in** | log in, authenticate, login |
| **sign-in** (noun/adj) | session, token, OAuth |
| **sign out** | log out, disconnect (for app sign-out) |
| **connect** (verb, health records) | authenticate, link |
| **your Alberta health records** | your PHR, your MHR data, your health data |
| **add-on** | extension, connector, bundle, MCP bundle |
| **AI service** | AI provider, provider |
| **AI key** / **AI service key** | API key |
| **data source** | MCP, MCP server |
| **Alberta's sign-in service** | Alberta SSO |
| **access key** | API key (in MCP custom form) |
| **My Health Records** | MHR (keep brand name) |
| **AHS MyChart** | MyChart alone (keep brand name) |
| **MyAlberta Digital ID** | keep as-is (official Alberta brand) |
| **assistant** | agent, AI agent |
| **message** / **question** | prompt, query |
| **install file** / **add-on file** | bundle, .mcpb |
| **data source address** | endpoint, URL (in user-facing labels) |
| **Canada** | Canadian (for geographic descriptions) |

## Decisions

- "Sign in" (two words, verb). "Sign-in" (hyphen, noun/adjective).
- "Alberta health records" = catch-all for all Alberta provincial records.
- MCP jargon removed entirely from user-visible headings and body copy.
  Settings pages formerly titled "MCP Servers" → "Data Sources".
- "extension" → "add-on" throughout (email, privacy page).
- Error messages follow: what happened + what to do next.
- Medical advice disclaimer: "Always talk to your doctor or pharmacist."
  Not "consult your healthcare provider" (still acceptable).
